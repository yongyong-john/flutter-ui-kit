# Flutter UI Kit

A Flutter project showcasing various UI components and design patterns.

## 📱 Platform Support

- ✅ Android
- ✅ iOS

## 🛠 Tech Stack

- **Framework**: Flutter
- **Language**: Dart
- **Android**: Kotlin
- **iOS**: Swift

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (latest stable version)
- Android Studio / VS Code
- Xcode (for iOS development)

### Installation

1. Clone the repository

```bash
git clone https://github.com/yongyong-john/flutter-ui-kit.git
```

2. Navigate to project directory

```bash
cd flutter-ui-kit
```

3. Get dependencies

```bash
flutter pub get
```

4. Run the app

```bash
flutter run
```

## 📦 Project Structure

```
lib/
├── main.dart          # App entry point
├── screens/           # UI screens
├── widgets/           # Reusable widgets
└── utils/             # Utility functions
└── description/       # Description of the message

android/              # Android-specific code
ios/                  # iOS-specific code
```
